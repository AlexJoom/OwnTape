# OwnTape — brand marks

| File | Use |
|---|---|
| `lockup-light.svg` / `lockup-dark.svg` | **Primary logo.** Icon tile + "OwnTape". README header, website, store. |
| `wordmark-light.svg` / `wordmark-dark.svg` | Secondary wordmark: the "O" is the record mark. Use at 24 px height or more. |
| `build-wordmark.py` | Regenerates the 4 SVGs (needs `fonttools`). |
| `proposal-reel/` | Optional tape-reel icon proposal. **Not adopted** (see below). |

- Letters: Noto Sans Bold, converted to paths (SIL Open Font License, logo use allowed). The SVGs need no font.
- Colours: text `#16181D` (light) / `#FFFFFF` (dark); mark `#4338CA` (light) / `#A5B0FF` (dark).
- Clear space: at least the height of the "w" on all sides.
- With "Google Meet™" (compatibility only): the text must be smaller than the logo and stand apart from it, for example "OwnTape · Local recorder for Google Meet™". Never "OwnTape for Meet" as one logo.
- On a dark indigo background, add a thin light outline to the icon tile (as in the store tile and marquee).

## Tape-reel proposal

`proposal-reel/reel.svg`, `reel-16.svg`, `reel-16.png`, `comparison.png`.
It is legible at 16 px. But two reels + a line is the common **voicemail** symbol, so users can think that it is a phone or voicemail app. It also shows "tape" but not "record". Recommendation: keep the ring-and-dot icon.
